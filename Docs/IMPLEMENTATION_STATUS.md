# 灰盒原型实现状态

## 新增：临时双人联盟与击杀计分

- 玩家可向附近存活玩���发送联盟邀请；目标接受后成为双人临时联盟。
- 邀请和联盟列表经 GameState 复制，客户端可用于显示邀请与关系状态。
- 每名玩家最多属于一个双人联盟；邀请和接受时服务端均重新校验存活状态、距离与关系占用。
- 玩家可主动解除联盟；淘汰、断线时清除联盟及相关邀请。联盟不共享最终胜利。
- 默认关闭盟友伤害，可在 GameMode 配置启用；服务器在扣血前检查联盟关系。
- 击杀非盟友玩家时给击杀者 PlayerState 累加分数；超时优先比较击杀分，再比较存活玩家生命值和 PlayerId。
