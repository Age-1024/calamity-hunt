# 灰盒原型实现状态

## 本次新增：实体皇印掉落与拾取

- 皇印从持有者死亡/服务器调用 DropCrown 后，在其位置生成复制的 `ACalamityCrownPickup`。
- 掉落皇印使用服务器权威距离检查，客户端只能通过角色 Server RPC 请求拾取。
- 拾取成功后销毁掉落 Actor、同步持有者并清空旧引导状态。
- 皇印在配置时间内未被拾取会销毁并重置，之后玩家可重新在祭坛引导。
- 皇印 Actor 使用引擎自带 TextRender 组件作为灰盒可视标识，不依赖外部美术资产。
