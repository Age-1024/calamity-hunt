# 灰盒原型实现状态

## 新增：普通异灵与契物驯服

- 新增复制的 `ACalamityCreature`：可受伤、追逐最近目标、近距离攻击；野生状态以玩家为目标。
- 玩家角色有一个原型契物（TamingItems），服务器在距离、存活��资源和异灵状态验证通过后才消耗并驯服。
- 驯服仅在异灵生命值降至最大生命值设定比例以下时成功；默认阈值为 50%。
- 驯服后异灵不攻击主人或主人联盟成员，转而追击其他存活玩家。
- 异灵血量、是否死亡、驯服归属复制到客户端。

## 限制和验证

这只是原型 AI：追逐使用 CharacterMovement 的 AddMovementInput，不含寻路网格、障碍绕行、动画和复杂行为树；测试地图需要可行走地面。异灵尚未自动生成，需在关卡中放置 `ACalamityCreature` 或其 Blueprint 子类。每位玩家目前只有一个原型契物，无拾取物/库存 UI。

当前提交尚未在 UE 5.5 编译验证。重点检查 AIModule 依赖、UHT 生成、复制 Actor 与 CharacterMovement，并在 Dedicated Server 下测试驯服、盟友保护和伤害。
