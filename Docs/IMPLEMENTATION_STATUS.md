# 灰盒原型实现状态

## 新增：急救包补给点

- 新增可放置的复制急救包 Actor，玩家进入触发范围时由服务器恢复生命值。
- 治疗不会超过角色最大生命值；满血、已淘汰角色不会消耗补给点。
- 可配置治疗量和重生间隔；重生间隔设为 0 时不重生。
- 急救包可用状态经 RepNotify 同步，拾取后隐藏并关闭碰撞，重生后恢复。
- 使用引擎自带 TextRender 作为占位标签，没有引入外部美术资源。
