# 灰盒原型实现状态

## 新增：血月缩圈安全区

- 可在关卡中放置 `ACalamityBloodMoonZone`，以 Actor 位置为安全区中心。
- GameMode 进入 BloodMoon 阶段后开始缩圈；等待宽限时间后，安全区外存活玩家按配置间隔受到服务器环境伤害。
- 支持配置初始/最终半径、缩圈耗时、伤害宽限时间、伤害间隔和每次伤害。
- 安全区激活状态和当前半径复制到客户端；占位文字显示等待状态或当前半径。
- 不会对安全区内玩家、异灵或已淘汰角色造成缩圈伤害；玩家回到安全区即停止受伤。

## 使用方式

在关卡放置 `ACalamityBloodMoonZone`，将其放置在地图希望作为安全区中心的位置，并配置半径和伤害。GameMode 的 `BloodMoonStartSeconds` 决定何时开始血月，Zone 的 `ShrinkDurationSeconds` 决定血月开始后缩圈时长。

## 验证状态

没有 Unreal Engine 5.5 环境，未执行 UHT、C++ 构建或多人 PIE 测试。需要在 Dedicated Server 验证阶段切换、复制半径、缩圈计算、环境伤害间隔和玩家进出安全区；当前为固定中心的灰盒安全区，不含随机下一个圈、地图材质边界、警告 UI 或安全区移动。
