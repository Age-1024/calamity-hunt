# 灰盒原型实现状态

## 新增：异灵刷新点

- 新增可放置的 `ACalamityCreatureSpawner`，服务端按间隔生成配置的异灵类型。
- 可配置刷新间隔、范围、存活上限、是否开局立即刷新，以及各对局阶段的刷新开关。
- 只统计当前仍有效的异灵，达到存活上限时暂停生成；异灵死亡销毁后可再次刷新。
- 刷新 Actor 本身不复制；生成的异灵使用既有 Actor 复制/移动同步。
- 蓝图类可通过 `CreatureClass` 配置；默认使用 C++ 灰盒异灵。

## 使用方式

在关卡中放置 `ACalamityCreatureSpawner`，设置生成范围和间隔。建议把它放在可行走、无障碍的地面附近；当前异灵移动是简化 CharacterMovement 输入，没有 NavMesh 寻路和障碍绕行。
