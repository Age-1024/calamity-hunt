# 游戏设计摘要

项目是一个 20 人目标、初期以 4 人灰盒验证的 PvPvE 超自然生存竞技射击原型。

## 核心循环

```text
进入猎场
→ 搜刮资源
→ 使用枪械和有限战术能力对抗
→ 完成局内结盟或背叛
→ 引导皇祭坛并争夺皇印
→ 皇者持印存活或成为最后存活者
→ 开始结算
```

## 原型胜负规则

1. 所有玩家开局使用基础枪械。
2. 服务器权威记录淘汰；玩家死亡后进入观战。
3. 皇祭坛打开后，存活玩家可进行可打断的引导仪式。
4. 皇印持有者进入血月阶段时，对附近区域暴露模糊位置。
5. 皇者连续持印达到配置秒数后获胜。
6. 皇印掉落、易主或持有者死亡时，连续计时清零。
7. 任意时刻只剩一名存活玩家，该玩家立即获胜。
8. 超时且无皇印持有者时，按公开的局内贡献分决出胜者。

## 临时结盟

首版仅实现“创建、解除、有限位置共享”和可选友军伤害规则。结盟不能分配最终胜利；解除或背叛时应提示，数据由服务器记录。

## 后续系统

普通异灵、稀有觉醒、觉醒印记、尸潮、镜界和动态势力均为后续阶段。首版先证明：枪手无需觉醒也能击败觉醒或持皇玩家。

## 可配置数值

所有阶段时间、皇印持有秒数、祭坛地点、武器伤害、结盟人数上限和贡献分权重都应放进数据资产，禁止硬编码进角色逻辑。
