## 觉醒源与技能测试

- [ ] 只有服务器可授予觉醒印记，客户端不能直接设置 Mark。
- [ ] 玩家超出觉醒源范围时请求失败，源保持可用。
- [ ] 同一玩家已有印记时不能获取第二枚印记。
- [ ] 两个客户端同时请求同一觉醒源，服务器最多授予一个玩家。
- [ ] 消耗后的觉醒源状态在所有客户端隐藏并关闭碰撞。
- [ ] 未觉醒玩家、能量不足或冷却期间释放技能均无冲刺。
- [ ] 觉醒玩家冲刺后消耗能量并开始冷却；服务器同步能量和冷却。
- [ ] 能量只在服务器回复，且不会超过 MaxEnergy。
- [ ] 组件已添加到角色 Blueprint；Dedicated Server 与至少两个客户端测试。
