# 灰盒验收清单

## 联机

- [ ] 4 名玩家可连接同一 Dedicated Server
- [ ] 关键开火、死亡、皇印和结盟状态同步到所有客户端
- [ ] 玩家断线不会破坏皇印持有计时或对局终止
- [ ] 对局内每场最多在配置时限内结束

## 枪战

- [ ] 无觉醒玩家可击败持皇或觉醒玩家
- [ ] 弹药、护甲、命中和死亡由服务器判定
- [ ] 服务器拒绝距离、冷却或状态非法的请求
- [ ] 基础武器可在灰盒地图中正常拾取和使用

## 皇印

- [ ] 皇祭坛按配置时间打开
- [ ] 引导仪式可被打断
- [ ] 皇印可以拾取、掉落和易主
- [ ] 皇者持印连续存活达到配置秒数即可获胜
- [ ] 皇印掉落或易主时计时清零
- [ ] 皇印异常重置到祭坛

## 胜负

- [ ] 最后一名存活玩家立即获胜
- [ ] 超时规则按公开贡献分和击杀数执行
- [ ] 同分和随机顺序规则可复现并记录日志
- [ ] 不存在撤离点或带物资撤离胜利

## 测试记录

每场测试至少记录：

- 阶段时间
- 玩家击杀与死亡
- 皇印每次转移
- 结盟创建与解除
- 胜利原因
- 延迟与崩溃异常
