# CalamityHunt module

C++ module source for the UE 5.5 graybox. The current character class exposes `RequestFire` for Blueprint input binding. The GameMode implements the server-side phase clock, crown claim/drop calls, elimination tracking and prototype timeout resolution.

**Important:** this repository has not yet been compiled in an Unreal Engine environment. Run UHT and compile on UE 5.5 before treating the scaffold as build-verified. A Blueprint child/map/input setup is needed for an interactive playable test.
